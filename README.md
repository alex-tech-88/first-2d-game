🏰 Pixel Knight Platformer

A 2D pixel-art platformer about a brave knight, inspired by classic Mario-style games.

🎮 Description

Control a fearless knight as he:

Jumps across platforms

Collects coins

Avoids deadly traps

Defeats slime enemies

Your goal is to survive the level, avoid falling into hazards, and reach the end safely.

🛠 Built With

Godot Engine 4.6.1 stable

GDScript

2D physics

Pixel-art assets

📂 Project Structure

scenes/ — game scenes (player, enemies, platforms, main game)

scripts/ — game logic

assets/ — sprites, music, and sound effects

🚀 How to Run

Open the project in Godot and run game.tscn.
